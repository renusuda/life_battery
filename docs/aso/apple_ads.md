# 概要

Apple Adsの検索結果広告を少額で試し、キーワードごとの表示回数・タップ率・インストール率を集めるためのドキュメント。主な目的はASOのキーワード選定に使うデータ集めで、課金まで含めた回収の判断は今回の対象外とする。

## 実施概要

| 項目 | 内容 |
| --- | --- |
| 期間 | 2026-10-27 〜 2026-11-10 00:00 (14日間) |
| 予算 | 1日あたり合計700円、最大9,800円 |
| クレジット | 新規アカウントの100USDプロモーションクレジットを利用 |
| 掲載場所 | 検索結果のみ |
| 国と地域 | 日本のみ |
| 入札戦略 | 入札額の管理 (手動) |
| 検索マッチ | オフ |

総予算の設定項目がないため、1日の予算と終了日で上限を管理している。

## 初期設定

アプリを知らないユーザーに見つけてもらうためのキャンペーン。

| 広告 | Default Ad (デフォルトのプロダクトページ) |

| キーワード | マッチタイプ | 最大CPT入札額 | 人気 |
| --- | --- | --- | --- |
| 余命 | 完全一致 | 120円 | 1/5 |
| 余命 計算 | 完全一致 | 120円 | 1/5 |
| 寿命 計算 | 完全一致 | 120円 | 1/5 |
| 人生 残り時間 | 完全一致 | 100円 | 1/5 |

- 病気の告知や治療の検索を除外: 宣告、がん、病気
